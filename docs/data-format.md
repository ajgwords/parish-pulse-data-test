# Data Format

## CSV files (non-spatial metrics)

Each metric listed in `config/metrics.yaml` requires a CSV file in `data/metrics/`.

### Format rules

- **Row 1** — column headers
- **Column 1** — date (any consistent format works: `2024-06-01`, `Jun 2024`, `2024`)
- **Column 2** — the numeric value to plot
- **Column 3+** — optional additional columns (e.g. notes); the third column is shown as a tooltip on hover
- Blank rows are ignored
- Column names become labels in the chart — choose meaningful names

### Example

```
Date, Number of empty shops, Notes
2024-06-01, 6, Mainly on High Street
2024-12-01, 5,
2025-06-01, 4,
2025-12-01, 7, Charity shop closed
2026-06-01, 6,
```

- The chart title comes from `label` in `metrics.yaml`
- The Y-axis label comes from the second column header (`Number of empty shops`)
- The current value shown in the card comes from the **last row**

### Multiple metrics in separate files

Each metric should have its own CSV file. Reference them separately in `metrics.yaml`:

```yaml
- id: empty_shops
  data_file: "empty-shops.csv"

- id: footfall
  data_file: "footfall.csv"
```

### Tips

- Dates don't need to be evenly spaced — add a row whenever you have new data
- Values can be integers or decimals
- Commas in values should be avoided or quoted: `"1,234"` or just `1234`
- UTF-8 encoding is expected; save from Excel using "CSV UTF-8" if possible

## Hexagon spatial data

Spatial data is stored as attributes on the hexagon GeoJSON file at `data/spatial/hexagons.geojson`.

This file is generated by `parish-pulse setup` from the source GeoPackage files. You then enrich it in your GIS application.

### Adding data in QGIS or ArcGIS

See [docs/gis.md](gis.md) for step-by-step instructions.

The map can colour hexagons by any **numeric** attribute in the file. The attribute selector in the map sidebar will list all numeric columns automatically.

### Saving back

When saving from QGIS or ArcGIS, ensure:
- Format: **GeoJSON**
- CRS: **EPSG:4326 (WGS84)**
- File path: `data/spatial/hexagons.geojson` (overwrite the existing file)

After saving, run `parish-pulse update` and commit the updated file.
