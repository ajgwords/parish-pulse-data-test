# GIS Guide — Adding Data to Hexagons

The hexagon file (`data/spatial/hexagons.geojson`) is generated by `parish-pulse setup` with no attributes beyond the geometry. You add your own attributes in QGIS or ArcGIS to enable spatial visualisation on the map.

The map will automatically detect all numeric columns and let the user colour hexagons by any of them.

---

## In QGIS

### Opening the file

1. Open QGIS
2. Drag `data/spatial/hexagons.geojson` into the QGIS window, or use **Layer → Add Layer → Add Vector Layer**
3. The hexagons will appear over an empty canvas

Add a base map for context: **Web → QuickMapServices → OSM → OSM Standard** (install the QuickMapServices plugin first if needed).

### Adding a new attribute column

1. Right-click the hexagons layer → **Open Attribute Table**
2. Click the pencil icon (Toggle Editing)
3. Click **New Field** (the column icon with a + sign)
4. Set:
   - Name: e.g. `tree_cover` (no spaces — use underscores)
   - Type: **Integer** or **Decimal number**
5. Click **OK**

You'll see the new column in the table, filled with `NULL`.

### Filling in values

**Option A — Edit individual hexagons**

1. With editing enabled, select the Identify tool (the `i` cursor)
2. Click a hexagon on the map
3. In the panel that appears, click the value field and type a number
4. Move to the next hexagon

**Option B — Edit in the attribute table**

1. Click the cell in the table you want to edit
2. Type the value
3. Press Tab or Enter to move to the next cell

**Option C — Join from another dataset**

If you have a separate spatial dataset (e.g. a point layer of trees), use **Vector → Data Management Tools → Join Attributes by Location** to count or sum features per hexagon.

### Saving back to GeoJSON

1. When finished editing, click the pencil icon → **Save**
2. Right-click the layer → **Export → Save Features As**
3. Set:
   - Format: **GeoJSON**
   - File name: navigate to `data/spatial/hexagons.geojson` in your repo and overwrite
   - CRS: **EPSG:4326 — WGS 84**
4. Click **OK**

## In ArcGIS Pro

### Opening the file

1. In the Catalog pane, navigate to `data/spatial/`
2. Drag `hexagons.geojson` onto the map

### Adding attributes

1. Right-click the layer → **Attribute Table**
2. Click **Add Field** (in the Fields view, or via the ribbon)
3. Name the field (no spaces), set type to **Short**, **Long**, or **Double**
4. Save field changes
5. Edit values directly in the attribute table

### Exporting back to GeoJSON

1. Right-click the layer → **Data → Export Features**
2. Output format: **GeoJSON**
3. Output location: `data/spatial/hexagons.geojson`
4. In **Environments**, set Output Coordinate System to **GCS WGS 1984 (EPSG:4326)**
5. Click **Run**

---

## After saving

Once you've saved the updated `hexagons.geojson`, rebuild the dashboard and commit:

```bash
uvx parish-pulse update
git add data/spatial/hexagons.geojson web/dashboard-data.json
git commit -m "Update hexagon data"
git push
```

The map will now offer your new attribute in the "Colour by" selector in the sidebar.
